# Nails & Lashes Boom · сайт майстра Катерини

Статичний сайт (HTML + CSS + трохи JS), розміщений на GitHub Pages.

## Як оновити вільні віконця

1. Відкрийте файл `rozklad.json` на GitHub і натисніть олівець ✏️ (Edit).
2. Впишіть дні так:

```json
{
  "onovleno": "2026-11-24",
  "dni": [
    { "data": "2026-11-26", "posluga": "Манікюр", "hodyny": ["10:00", "14:30"] },
    { "data": "2026-11-27", "posluga": "Вії", "hodyny": ["12:00"] }
  ]
}
```

3. Натисніть **Commit changes**. Через 1–2 хвилини сайт оновиться.

Минулі дні сайт ховає сам. Якщо список порожній, на сайті з'являється напис «пишіть у Viber / дивіться сторіс».

> Автоматично брати години зі сторіс Instagram не можна: Instagram не дає читати сторіс без офіційного бізнес-API і сервера, а GitHub Pages сервера не має.

## Відгуки (автоматично)

Клієнтки пишуть відгук через кнопку «Залишити відгук» (Google Форма). Відповіді самі потрапляють у Google Таблицю «Новая форма (Ответы)», а сайт за кілька хвилин показує їх сам.

- Захист від ботів і спаму: у формі треба увійти в Google, один відгук з акаунта; відгуки з посиланнями сайт не показує.
- Прибрати поганий відгук: відкрийте таблицю «Новая форма (Ответы)» у Google Таблицях і видаліть рядок. З сайту він зникне за кілька хвилин.
- Файл `vidhuky.json` лишається запасним: те, що там є, показується, навіть якщо Google недоступний.

## Як замінити фото

Завантажте нове фото у репозиторій з тим самим ім'ям (наприклад `nails-03.webp`), або попросіть Claude обробити нове.

## Безпека

- Content-Security-Policy: дозволено лише власні файли сайту і плеєр SoundCloud (`w.soundcloud.com`) (вантажиться тільки після натискання «Музика»).
- Жодних сторонніх скриптів, шрифтів, лічильників чи cookie. Шрифти лежать у самому репозиторії.
- На сайті немає форм і паролів: нічого красти. Запис іде через Viber.
- Відгуки збираються через Google Форму: потрібен вхід у Google, один відгук з акаунта, посилання відфільтровуються. Сайт читає опубліковану таблицю відповідей тільки як текст (CSP дозволяє лише docs.google.com і googleusercontent.com).
- З фото і відео видалено метадані (EXIF, GPS-координати телефону).
- Дані з JSON виводяться тільки як текст (`textContent`), тому вставити шкідливий код через них не можна.
- `Referrer-Policy: no-referrer`, посилання назовні з `noopener noreferrer`.
- **Обмеження GitHub Pages:** він не дає ставити власні HTTP-заголовки (HSTS, X-Frame-Options, frame-ancestors). Якщо колись буде свій домен, його можна пропустити через безкоштовний Cloudflare і додати ці заголовки там.
- Акаунт GitHub: увімкніть двофакторну автентифікацію (Settings → Password and authentication), бо хто має доступ до акаунта, той може змінити сайт.
